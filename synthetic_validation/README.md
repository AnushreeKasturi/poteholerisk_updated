# Synthetic Formula-Consistency Validation

**This folder is NOT the project's real accuracy result.** The real,
honestly-evaluated result on actual Bengaluru accident data lives in
`../models_final/` (73.1% accuracy, held-out test set, Karnataka Police
records 2016–2023). See `../models_final/README_MODEL.md` for that result
and how it was reached.

## What's here instead

`synthetic_formula_validation.py` generates a synthetic dataset directly
from the paper's own equations (Eq. 1–7: pothole-based prior, weather
likelihood multipliers, Poisson traffic exposure, final risk score, and
LOW/MEDIUM/HIGH classification), then trains a classifier to recover the
risk category from the raw inputs (potholes, rain, wetness, visibility,
traffic flow, time of day).

This checks whether the DBN formulation is **internally consistent** — i.e.
whether a model can learn the shape of the formula's own decision boundary.
It does **not** measure real-world predictive accuracy, because the labels
are generated by the same deterministic formula the classifier is fit to,
with no real-world noise, missing variables (speed, driver behavior,
vehicle type), or human unpredictability.

## Result (held-out test set, 20%, stratified, random_state=42)

| Metric | Weighted | Macro |
|---|---|---|
| Accuracy | 93.6% | — |
| Precision | 93.2% | 87.9% |
| Recall | 93.6% | 82.9% |
| F1-score | 93.3% | 85.2% |

Per-class:

| Class | Precision | Recall | F1 |
|---|---|---|---|
| HIGH | 0.96 | 0.99 | 0.98 |
| LOW | 0.88 | 0.79 | 0.83 |
| MEDIUM | 0.79 | 0.70 | 0.75 |

Full report in `synthetic_classification_report.txt`, raw numbers in
`synthetic_metrics.json`, generated data in `synthetic_scenarios.csv`.

## How to cite this in the paper

Present this as a separate internal-consistency check, e.g.:

> "As an internal consistency check, a classifier trained to recover the
> DBN model's own risk categories from raw inputs under simulated
> conditions achieved 93.6% accuracy (Table X), confirming the formulation
> produces a learnable, well-separated decision boundary. This is distinct
> from the model's real-world evaluation (Section VI), which used actual
> Bengaluru accident records and achieved 73.1% accuracy — the gap reflects
> the difference between a formula recovering its own logic and predicting
> genuinely noisy, real-world outcomes."

Do **not** place this number in the same comparison table as real-data
benchmarks from other papers (e.g. Gbey et al., Jibunor et al., Talluri et
al.) — those are measuring a different thing.
